## 5. 可靠性结论与使用建议

### 5.1 高可靠（可直接使用）
- **P0 利润表 + 现金流量表主干**：`revenue` / `net_profit` / `operating_profit` / `operating_cost` / 三类 `*_cash_flow` / `capital_expenditures` / `depreciation_amortization` / `dividends_paid` 等均为 Yahoo 单源或双源对账一致（A 级）。三年趋势自洽：营收稳定在 ~HK$280B，净利润 23.5B→17.1B→11.8B 持续下滑，与 CKH 公开业绩一致。
- 资产负债表中 `cash`/`money_cap`/`lt_borr`/`st_borr`/`equity_attributable_to_owners`/`minority_int`/`defer_tax_*` 等为 A 级。

### 5.2 不可靠 / 需谨慎使用
1. **Provider 源分歧（A- 级，8 个）**：`total_assets`(Δ≈111.8B)、`fix_assets`(Δ≈68.8B)、`acct_payable`(Δ≈50.6B)、`total_liabilities`(Δ≈45.2B)、`accounts_receiv`(Δ≈23.3B)、`total_cur_assets`(Δ≈20.6B)、`total_cur_liab`(Δ≈13.1B)、`inventories`(Δ≈2.6B)。AKShare 与 Yahoo 对该 issuer 资产负债表科目口径差异巨大（疑似合并范围/重分类不同），管线按策略选了 Yahoo。**下游不应信任 AKShare 对 00001 的资产负债表科目**；即便选定值也建议以年报 PDF 为准。
2. **LLM 单源补充（B/B- 级，17 个）**：provider 无覆盖、由 `gpt-5.5`（relay）抽取。较 DeepSeek 时代的两处已知问题均已解决/改善：
   - `dps`：本轮 gpt-5.5 = **1.602 HK$/股 @p17**，与历史 Codex 基线一致——DeepSeek 时代的 2.312 跨抽取器冲突就此裁决（DS 误把口径取错）。
   - `segment_revenue_profit`：现抽出**分部收入合计 507,297 + EBITDA 合计 10,481**（p153），较 DS 单一总额有改善，但仍非完整逐分部明细，置信 0.79（B-）。
   - alias-lifecycle 闭环成果：`receivables_aging`（完整账龄表 @p229）与 `related_party_receivables_payables`（p269 注释文本）首次进入 present——正是别名转正 batch 2 的两个 motivating case。`non_oper_income`(976)/`non_oper_exp`(12,327) 亦转正。
   - B-（置信 <0.85 且进入终态）2 项：non_oper_exp(0.78)/segment(0.79)——表 4.3 页码抽查优先级最高。（equity_attributable/inventories 的 LLM 低置信值被 provider clean 值覆盖，不入终态。）
   - 已知解析缺口：`capitalized_interest` 因 LLM 返回括号负数 `'(21)'` 解析失败（extraction_failed），属 money-parser 格式缺口，待修。
3. **合成零（A0 级）**：`repurchase_of_stock` 经 `absence_means_zero` 合成判 0（2024/2025 各年），provider 历史跟踪该行、本期省略 → 判 0。PDF 仅见回购监管样板条款与会计政策、无实际回购交易行，LLM 也拒绝确认（「financing section 不完整」）→ **0 大概率为真但属合成零**，若用于回购/股东回报判断须核对年报；`buyback_cancellation_progress`（注销进度）仍缺失。
4. **缺失 / 冲突未解（C 级，18 个，较 DS 基线 -3）**：
   - 多为 HK 报表本就不单独披露的 A 股口径科目：`c_pay_to_staff`/`c_paid_for_taxes`/`receiv_tax_refund`/`stock_based_compensation`/`capitalized_rd`/`rd_exp`/`non_oper_income`/`non_oper_exp` —— 属 issuer 结构性缺失，非管线缺陷。
   - `gross_profit`：provider 间 normalized_value_conflict 未解（AKShare↔Yahoo 毛利口径不一），三年均无定值。
   - `selling_general_administrative`：terminal_unverified（pdf_required，Yahoo 有值但策略要求 PDF 佐证未达成）。

### 5.3 一句话总结
> FY2025 覆盖 **50/68 (74%)**（DS 基线 47，Codex G4-C 基线 47）。可直接使用的是 **provider 对账一致的 A 级利润表/现金流主干**；**资产负债表科目存在 AKShare↔Yahoo 大额口径分歧（A-）**，**LLM 单源字段（B/B-）须按表 4.3 抽查**（B- 四项优先），**`repurchase_of_stock` 为合成零（A0）须核对年报**，**C 级缩至 18 个**（多为 issuer 真不披露的 CN 概念科目）。
